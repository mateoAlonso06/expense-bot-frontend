# Button

Pill-shaped action in three variants: primary (`brand`), dark (`surface-inverse`) and secondary (outlined).

- Height at least 44px (52px for hero CTAs), `radius-pill`, `label` text style (16px in CTAs).
- **Primary**: `brand` fill, `on-brand` text. One per view.
- **Dark**: `surface-inverse` fill, `ink-inverse` text. Nav CTA ("Empezar gratis").
- **Secondary**: `surface-000` fill, 1px `border-strong`, `ink` text.
- An optional leading 20px stroke icon, `space-2` gap.
- Use a real `<a href>` for navigation and `<button>` for actions. Give it a visible focus ring (2px `brand`, 2px offset).
- Labels are verbs in voseo: "Abrir en Telegram", "Crear cuenta", "Ver cómo funciona".
