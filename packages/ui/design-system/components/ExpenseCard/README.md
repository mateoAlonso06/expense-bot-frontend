# ExpenseCard

resiAI's confirmation that an expense was recorded: status line, amount, chips and description.

- Container: `surface-000`, `radius-md` (bottom-left 4px when shown as a chat reply), `shadow-bubble`, padding 14px, `space-3` gap.
- **Status line**: `label` 13px in `brand` with a check icon. Copy depends on the input format: "Gasto registrado" (text), "Leí tu ticket" (photo), "Te escuché" (audio).
- **Amount**: `amount` style, ARS formatting with decimals (`$ 23.890,00`).
- **Chips**: the category Chip, then a neutral date Chip ("Hoy", "Ayer", or `dd/mm`).
- **Description**: `body` 14px in `ink-muted`, sentence case, generated by the agent ("Compra en supermercado").
- In the web panel the same content becomes a list row: a 36px `radius-sm` tile in the category pair with the input format (TXT, IMG, AUD), description + "Categoría · fecha", amount right-aligned in tabular numerals.
